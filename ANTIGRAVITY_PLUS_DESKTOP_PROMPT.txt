```typescript
interface IDEState {
  // Workspace and File System
  workspacePath: string | null;           // Absolute path to open root directory
  workspaceName: string | null;           // Display name of current directory
  fileTree: TreeNode[];                   // Recursive representation of directory
  expandedFolders: Record<string, boolean>; // Path map of expanded folders

  // Editor Buffers
  openFiles: OpenFile[];                  // Array of open tabs
  activeFilePath: string | null;          // Path of currently active buffer
  cursorPosition: { line: number; col: number }; // Live line and column tracking

  // UI Geometry and Panel States
  leftPanelWidth: number;                 // Typically 250px (or 0px when collapsed)
  isExplorerOpen: boolean;                // Left sidebar visibility
  isChatOpen: boolean;                    // Right-side AI agent sliding panel state
  
  // 6-Agent Swarm Telemetry
  agentLifecycle: "idle" | "thinking" | "writing" | "waiting" | "done" | "error";
  agentCurrentAction: string;             // Human-readable status line
  fileChangesHistory: FileDelta[];        // Tracks lines added/removed per file
  chatMessages: ChatMessage[];            // Multi-turn context conversation
}

interface TreeNode {
  name: string;
  path: string;
  isDirectory: boolean;
  children: TreeNode[] | null;
}

interface OpenFile {
  path: string;
  name: string;
  content: string;
  isDirty: boolean;
}

interface FileDelta {
  path: string;
  linesAdded: number;
  linesDeleted: number;
  status: "created" | "modified" | "deleted";
}

interface ChatMessage {
  id: string;
  sender: "user" | "agent" | "system";
  text: string;
  timestamp: number;
  deltas?: FileDelta[];
}
```

SECTION 6: UNLIMITED CONTINUITY & SELF-HEALING ENGINES
################################################################################

6.1 CONTINUITY ENGINE (UNLIMITED TOKEN GENERATION)
   - Problem: Standard LLMs truncate responses when hitting token limits on large projects.
   - Solution:
     * AST & Micro-Chunking: The continuity engine splits large files into cohesive modules, classes, and methods.
     * Sequential Assembly: Agents write module by module, updating progress state between turns.
     * State Persistence: Every token generation pass is serialized into a workspace snapshot folder (`.antigravity_state/`). If an interruption occurs, generation resumes seamlessly from the exact byte offset.

6.2 SELF-HEALING & AUTONOMOUS BUG FIXING LOOP
   - Workflow:
     1. Agent writes code + tests.
     2. Agent launches test runner inside the embedded terminal.
     3. If tests fail (`exit code != 0`):
        * The error stack trace is captured from the terminal stdout.
        * A self-healing subagent parses the exception and failing line numbers.
        * The patch is applied to the file via native disk write.
        * Tests are re-executed automatically.
     4. Loop repeats until 100% pass rate or max 5 iterations reached before notifying user.

SECTION 7: SECURE PRELOAD IPC BRIDGE SPECIFICATION
################################################################################

In `preload.js`, expose the following API under `window.electron`:

```javascript
const { contextBridge, ipcRenderer } = require('electron');

contextBridge.exposeInMainWorld('electron', {
  // Native OS Directory Picker (Zero Browser Permissions)
  openFolder: () => ipcRenderer.invoke('dialog:openFolder'),

  // Recursive Disk Scanner
  readDirRecursive: (folderPath) => ipcRenderer.invoke('fs:readDirRecursive', folderPath),

  // File I/O
  readFile: (filePath) => ipcRenderer.invoke('fs:readFile', filePath),
  writeFile: (filePath, data) => ipcRenderer.invoke('fs:writeFile', filePath, data),
  deleteItem: (itemPath) => ipcRenderer.invoke('fs:deleteItem', itemPath),
  renameItem: (oldPath, newPath) => ipcRenderer.invoke('fs:renameItem', oldPath, newPath),

  // Terminal PTY Channel
  sendTerminalInput: (command) => ipcRenderer.send('terminal:input', command),
  onTerminalOutput: (callback) => ipcRenderer.on('terminal:output', (_, data) => callback(data)),

  // Native Window Management
  minimize: () => ipcRenderer.send('window:minimize'),
  maximize: () => ipcRenderer.send('window:maximize'),
  close: () => ipcRenderer.send('window:close'),
});
```
